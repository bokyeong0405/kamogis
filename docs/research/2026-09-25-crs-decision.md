# 원본 좌표계 해석 기록

- 날짜: 2026-09-25
- 대상: 버스정류소 20260902, 따릉이 대여소 202606 원본
- 원천 버스 페이지: `WGS84 (EPSG-5179)`로 표기되어 있어 CRS 이름과 코드가 충돌한다.
- 원본 값: 버스 X≈126~127, Y≈37, 따릉이는 경도·위도 필드로 제공한다.
- 사용자 판단: 원천의 5179 표기는 오류이며 WGS84 경위도로 해석한다.
- 사용자의 첫 메시지에 있던 `4156`은 확인 질문 후 `4326(WGS84)이 맞음`으로 정정되었다.
- 결정: 이 프로젝트에서 두 원본 좌표를 **EPSG:4326**으로 해석한다. 이는 프로젝트의 명시적 해석 결정이며 제공기관이 수정·확인한 사실로 주장하지 않는다.
- 숫자 형태만으로 datum을 확정할 수 있다는 일반 규칙으로 확장하지 않는다.

## 저장 방식

- 원본 XLSX는 그대로 보존하며 checksum도 유지한다.
- PostgreSQL: `ST_SetSRID(ST_MakePoint(longitude, latitude), 4326)`로 geometry(Point,4326)에 저장한다. 좌표값은 변환하지 않는다.
- MongoDB: `{"type":"Point","coordinates":[longitude, latitude]}`로 저장한다.
- 적재 CLI에 `--crs=4326`을 명시해야 쓰기가 가능하다. 임의 CRS를 자동 추정하거나 5179→4326 변환을 실행하지 않는다.
- OpenLayers 화면 좌표(EPSG:3857) 변환은 이후 화면 연결 단계에서 수행한다.

EPSG:4156은 S-JTSK로 서울 WGS84 데이터와 다르다. 참조: https://spatialreference.org/ref/epsg/4156/
